# H 436 Provisional Name Headings

## Validation rules

1. A name heading coded "provisional" (value `c` in 008/33) is valid for assignment as a subject heading as established, without further action. (H 436)
2. If the work being cataloged contains information enabling the heading to be fully established, consider revising the provisional heading (or requesting a descriptive cataloger to do so). (H 436)

## Full text

**BACKGROUND:** When a descriptive cataloger determines that a name heading cannot be satisfactorily established according to descriptive rules because of inadequate information about the person, corporate body, or uniform title the heading represents, a "provisional" name heading is established, coded c in field 008/33 (the Level of Establishment box on the 008 input screen in authority records in the LC ILS). Name headings coded "provisional" may be assigned as subject headings without further action.

If a name heading coded "provisional" is needed for assignment as a subject heading, assign the heading as established, or, if the work being cataloged contains additional information that will enable the heading to be fully rather than provisionally established, consider revising the heading or requesting a descriptive cataloger to do so.
