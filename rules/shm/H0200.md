# H 200 Preparation of Subject Heading Proposals

## Validation rules

1. A heading is authorized for assignment without a proposal only if it is: a name heading in the LC/NACO Name Authority File (H 430); a subject heading or subdivision established in Classification Web Plus (H 40); a heading built with free-floating subdivisions under an established name or subject heading (H 1095); or a free-floating phrase appended to an established name or subject heading (H 362). Any other heading must be proposed and approved before use. (H 200 sec. A)
2. A heading-subdivision combination is tagged by its $a element: e.g. `Jesus Christ--Date of death` is 100, `Harvard University--Student housing` is 110, `Super Bowl--Records` is 111, `Beowulf--Characters` and `Bible--Quotations in the Book of Mormon` are 130. (H 200 sec. C.2)
3. Time periods and events that are subdivisions under places are geographic (151) headings; topical headings include events that are not subdivisions under places, groups of legendary characters, and deities. (H 200 sec. C.2.a, C.2.b)
4. Groups of fictitious characters take the qualifier `(Fictitious characters)` (e.g. `Teenage Mutant Ninja Turtles (Fictitious characters)`); family name headings take the form `[Name] family` (e.g. `Smith family`). (H 200 sec. C.2.c, C.2.d)
5. Family name headings may not be subdivided geographically (008/06 fixed at Not Subd Geog). (H 200 sec. D.2 note, Appendix 2)
6. 008/06 values: May Subd Geog = subdivided geographically - indirect; Not Subd Geog; No Attempt to Code (no geographic information after the heading; not currently divided geographically). (H 200 sec. D.2)
7. A 4XX (UF) must not conflict with an existing heading or UF reference, except the `$w nne` 4XX recording the earlier form when a heading is split (H 193). UFs are listed alphabetically and normally carry no $w. (H 200 sec. D.5.a, D.5.c)
8. Every 5XX must be a currently valid (or proposed) heading; BTs carry `$w g`, RTs carry no $w and need reciprocal 5XX; BTs are listed alphabetically, then RTs alphabetically. LC does not use `$w h` (narrower term) or record NTs in broader-term records. (H 200 sec. D.5.a, D.5.d, D.5.e)
9. A 5XX may be a generic term divided by place or a heading with a free-floating subdivision (e.g. `Mountains--Colorado`, `Oxygen--Toxicology`) even if no authority record yet exists for that string. (H 200 sec. D.5.d)
10. Only records with evaluated references (008/29 = a) are used as reference patterns. (H 200 sec. D.5.b)
11. Geographic headings carry a 781 giving their form as a geographic subdivision (per H 830); if blank, the system adds a 667 stating the heading is not valid as a geographic subdivision (H 836). Such a heading must not be used as $z. (H 200 sec. D.8)
12. 053 coding: one field per number/span; span start in $a and end in $b, both with class letters, no hyphen; qualifying term in $c without parentheses (e.g. `053 #0 $a HG289 $b HG297 $c Finance`). (H 200 sec. D.3)
13. Scope notes (680) and general see (260) / see also (360) references use $i for explanatory text and $a for headings/subdivisions referred to (e.g. `360 ## $i subdivision $a Apologetic works $i under individual denominations, e.g., $a Catholic Church--Apologetic works`). (H 200 sec. D.7, D.9, D.10)
14. Do not cite LC patterns or the SHM in 670; use 952 (`952 ## $a LC pattern: Authors, Zimbabwean`, `952 ## $a SHM H 1334`). One 675 lists sources consulted without the term. The work cataloged is the first 670. (H 200 sec. D.6, D.12)
15. A proposal is unnecessary (and should not be made) for a string using a free-floating subdivision or phrase (H 362, H 1095-H 1200), or that duplicates an existing heading. (H 200 sec. E)
16. Order of fields in subject authority records: 010, 040, 053, 1XX, 260, 360, 4XX, 5XX, 667, 670, 675, 680, 681, 781, 952, 907, 910. (H 200 Appendix 1)
17. [LC practice] 952 `Bib. Records to be changed:` gives the count (0 if none) and LCCNs if under fifteen. (H 200 sec. D.11)

## Full text

### A. Background

Headings that are in one of the following categories are authorized to be assigned as subject headings:

- Name headings established in the LC/NACO Name Authority File (cf. H 430)
- Subject headings and subdivisions established for inclusion in the authoritative LCSH database, Classification Web Plus (cf. H 40)
- Subject headings constructed by using free-floating subdivisions under established name or subject headings (cf. H 1095)
- Subject headings consisting of free-floating phrases appended to established name or subject headings (cf. H 362)

Any other subject heading must be proposed by a cataloger and submitted to the Policy, Training, and Cooperative Programs Division (PTCP) of the Library of Congress. The proposal must be approved during PTCP's editorial process for inclusion in *Library of Congress Subject Headings* (LCSH) before its use as a subject heading is authorized.

This instruction sheet explains the general requirements for new subject heading proposals and lists the steps to follow to create a subject authority record using the ClassWeb Plus Subject Heading Proposal System. These procedures apply only to the creation of new subject authority records. For the procedures to follow in making changes to existing records, see H 193, H 193.5, H 194, H 195, and H 196.

Note: These instructions provide tagging and subfield coding information for the most common situations that are encountered in creating subject authority records. In more complex situations it may be necessary to consult the MARC 21 authority format for detailed content designation information.

### C. General information about the Classification Web Plus Proposal System

The subject heading proposal system displays proposed changes to LCSH using a special version of the subject heading browser. It combines the most current version of the existing subject heading data in black text, proposals for new subject headings in bright green text, and proposals for modifications to existing headings in an orange-brown text.

### C.1. Accessing the proposal system

#### C.1.a. LC catalogers

- Go to URL: https://lcconline.info/Menu/
- Click on: *Proposal system* under LC Subject Headings
- Click on: *Propose a New Heading*
- Click on: The category of subject heading to be proposed (see sec. C.2, below)
- Login: Key in the username and password

#### C.1.b. SACO members

- Go to URL: https://classweb.org/Proposal/
- Click on: *Proposal system* under LC Subject Headings
- Click on: *Propose a New Heading*
- Click on: The category of subject heading to be proposed (see sec. C.2, below)
- Login: Key in the username and password

### C.2. Accessing templates for new headings

On the LC Subject Heading Proposal Menu page, click on the appropriate option for the type of heading being established. This retrieves one of the various templates, or forms, that have been designed for different categories of headings.

Note: Subject headings and references are tagged according to the definitions in the *MARC 21 Format for Authority Data*. For heading-subdivision combinations in 1XX, 4XX, or 5XX fields, the tag is based on the $a subfield, and the corresponding template is used to create it. For example, since the heading *Jesus Christ--Date of death* is tagged 100 (based on the $a subfield *Jesus Christ*), the Personal Name Heading template is used to create it; since *Harvard University--Student housing* is tagged 110 (based on the $a subfield *Harvard University*), the Corporate Body Heading (Buildings, etc.) template is used; since *Beowulf--Characters* is tagged 130 (based on the $a subfield *Beowulf*), the Uniform Title Heading template is used; etc.

Each of the templates is discussed specifically in sec. C.2.a-C.2.i, below.

#### C.2.a. Topical heading

Use this template to establish topical subject headings, including events that are not subdivisions under places, groups of legendary characters and deities, etc.

#### C.2.b. Geographic heading

Use this template to establish geographic features and named entities that have been designated as geographic in nature (see H 405). Also use this template to establish time periods and events that are subdivisions under places.

#### C.2.c. Group of fictitious characters heading

Use this template to establish headings for groups of characters, e.g., *Teenage Mutant Ninja Turtles (Fictitious characters)* (see H 1610).

#### C.2.d. Family name heading

Use this template to establish family name headings used as subjects, e.g., *Smith family* (see H 1631.5).

#### C.2.e. Corporate body heading (Buildings, etc.)

Use this template to establish subdivisions under named entities that are corporate bodies, and to establish subject headings for named entities that have been designated as similar to corporate bodies and tagged 110 (see H 405).

#### C.2.f. Meeting heading

Use this template to establish subdivisions under headings for meetings and events that are tagged 111, e.g., *Super Bowl--Records*.

#### C.2.g. Personal name heading

Use this template to establish subdivisions under personal names, e.g., *Jesus Christ--Betrayal*.

#### C.2.h. Uniform title heading

Use this template to establish subdivisions under uniform titles, e.g., *Bible--Quotations in the Book of Mormon*.

#### C.2.i. General see reference

Use this template to establish general see references (150/260) (see H 374).

### C.3. General information about navigating the templates

#### C.3.a. Fixed vs. editable data

Some areas of the templates contain data that cannot be edited by the user. Other areas have fields in which the cursor can be placed and data can be entered or edited by the user. In many of these editable fields, some data has already been provided by the system. For example, in the 1XX field, the system includes the data *$a* by default. Default data provided by the system can in most cases be edited or deleted by the user if necessary.

#### C.3.b. Adding subfields in editable fields

The system uses the dollar sign ($) to represent a delimiter. In order to add a new subfield to an existing field, type a dollar sign followed by the appropriate subfield code letter.

Example:

```
150 $a Greenhouse gases [existing subfield]
150 $a Greenhouse gases $x Law and legislation [new subfield added]
```

#### C.3.c. Adding new fields to the template

Immediately above the first editable field in the template is an *Insert field* menu. If it is necessary to add a new field to the template, select the radio button of the existing field above which the new field is to be inserted. Then click the down arrow on the *Insert field* menu in order to display a list of available fields. Click on the desired field, and it will be inserted immediately above the field whose radio button was selected.

Note: If no radio button is selected, the system will automatically insert the new field before the next higher numbered tag in the template.

#### C.3.d. Fields that the user leaves blank

Any field that appears in a basic template and is left blank by the user is automatically deleted by the system when the record is saved. It is not necessary for the user to take any action to remove an unneeded field from a template.

Note: If desired, a field may be removed by selecting the radio button of the field and clicking the *Remove Field* button.

### D. General instructions for completing the proposal template

### D.1. "Generated by" field

At the top of the form select the appropriate radio button.

#### D.1.a. Library of Congress catalogers

Library of Congress catalogers have four options from which to choose.

- **Book.** Select this button if any non-Priority-1 bibliographic resource is being sent to PTCP with the proposal, such as a book, etc. This should be an exception.
- **No Book.** Select this button if no bibliographic item is being submitted with the proposal. This should be the preferred option.
- **CIP.** Select this button if the proposal is being made in connection with the cataloging of a CIP.
- **Coop.** Select this button if the proposal is being input by an LC staff member on behalf of another library.

#### D.1.b. Catalogers in SACO institutions

Catalogers in SACO institutions have two options from which to choose.

- **Not a Library of Congress CIP.** Select this button if the proposal is not being submitted in connection with the cataloging of an LC CIP.
- **Library of Congress CIP.** Select this button if the proposal is being submitted in connection with the cataloging of an LC CIP.

Note: The Proposal System automatically codes SACO proposals as *Coop*, based on the user's login information.

### D.2. Field 008/06 (Geographic subdivision)

The values that appear as radio buttons for the 008/06 field in the templates are as follows:

- May Subd Geog = Subdivided geographically - indirect
- Not Subd Geog = Not subdivided geographically
- No Attempt to Code = No geographic information will appear after the heading. This value also indicates that the heading is not currently divided geographically.

H 364 provides guidelines on how to choose the appropriate code for geographic subdivision. Following those guidelines, select the appropriate radio button.

Note: Field 008/06 does not appear in the templates for certain types of headings because it is set by default and cannot be edited. For example, in the template for family name headings, the 008/06 is set to Not Subd Geog and may not be changed.

### D.3. LC Classification Number (053 field)

Follow the rules and guidelines in H 365 to determine whether to assign a class number to the heading. Enter each number or span of numbers in a separate 053 field. For a single number, use the $a subfield. For a span of numbers, use the $a subfield for the beginning number of the span and add a $b subfield for the ending number. Provide the full class number (including class letters) for both the $a and $b subfields. Do not key in a hyphen. Enter the appropriate qualifying term, if any, in a $c subfield. Do not enclose data in the $c subfield in parentheses.

Example:

```
053 #0 $a HG289 $b HG297 $c Finance
```

053 fields left blank will be automatically deleted by the system when the record is saved (see sec. C.3.d, above).

If an additional 053 field is required, or if the template does not provide an 053 field but one is needed, add it by using the appropriate technique described in sec. C.3.c, above.

### D.4. The heading (1XX field)

Enter the text of the proposed heading in the 1XX field. If a heading-subdivision combination is being proposed, create the necessary subfields using the technique described in sec. C.3.b, above.

### D.5. Tracings and references

#### D.5.a. General rule

Record all UF, BT, or RT references as tracings, that is, as 4XXs or 5XXs. Determine by searching the subject headings in ClassWeb Plus that any proposed 4XX does not conflict with an existing heading or UF reference (see exception below under Note in sec. D.5.c.). Confirm that any proposed 5XX exists as a currently valid heading.

#### D.5.b. Reference patterns

Many new headings belong to special categories having their own prescribed sets of references, such as names of individual structures, monuments, or geographic features. Specific subdivisions also have characteristic reference patterns. These can be determined by consulting individual instruction sheets in the *Subject Headings Manual* and/or by examining existing subject authority records for other headings in the category. Use only authority records whose references have been evaluated (that is, those with the value *a* in field 008/29) as patterns for new proposals.

#### D.5.c. "Used For" references (4XX fields)

Follow the rules and guidelines in H 373 for making "Used for" (UF) references. Record UF references in 4XX fields. Use the technique described in sec. C.3.c, above, to add additional blank 4XX fields to the template. List these fields in alphabetical order. Do not add $w control subfields to 4XX fields except under the conditions described in the note below. Provide authority citations in 670 fields to support variant forms of names and alternate terminology (see sec. D.6 on Citation of sources).

Example:

```
150 ## $a French fries
450 ## $a Chips (French fries)
450 ## $a French fried potatoes
450 ## $a French frieds
450 ## $a Fries, French
```

Note: New subject authority records are sometimes created because a subject heading is being canceled and replaced by two or more new headings (cf. H 193). In those cases, add a 4XX field containing the old form of the heading to each of the new authority records. These 4XX fields headings may conflict. Identify this as the earlier form of the heading by adding, at the beginning of the field, a $w control subfield with the code nne.

#### D.5.d. Broader terms and Related terms (5XX fields)

Follow the principles in H 370 for making broader term (BT) and related term (RT) references. Record BT references in 5XX fields that have a $w control subfield containing the value *g*. This control subfield identifies references as broader terms. List them in alphabetical order. Record RT references in 5XX fields that have no $w control subfield. The absence of the control subfield identifies the references as related terms. List them in alphabetical order immediately following the list of BT references. Use the technique described in sec. C.3.c, above, to add additional blank 5XX fields to the template, as needed.

Example:

```
150 $a Carpets
550 $w g $a Floor coverings [a broader term]
550 $a Rugs [a related term]
```

Note: For each related term 5XX, a reciprocal 5XX must be added to the authority record for the heading being used as a reference. To do this, follow the procedure described in H 195, Changing References in Subject Authority Records.

There must be an authority record in the subject authority file for each subject heading used as a 5XX. In cases where a 5XX is made from a generic term divided by place or from a topic divided by a free-floating subdivision, for example, *Mountains--Colorado* or *Oxygen--Toxicology*, an authority record for the generic term divided by the specific place or for the specific heading-subdivision combination needed in the 5XX may not yet have been created. In these cases, it is not necessary for the cataloger to create the authority record; editorial staff will create it.

#### D.5.e. Narrower terms (NTs)

Make references from the new heading being proposed to existing narrower headings by adding the new heading as a BT (that is, a 5XX field having a $w control subfield containing the value *g*) to the existing authority records for the narrower terms. Do this by following the procedures in H 195 for changing references in existing subject authority records and submitting the proposal for each changed record together with the proposal for the new heading. Although the MARC 21 format provides value *h* to identify narrower terms in a $w control subfield of 5XX fields, the Library of Congress does not use this value nor include narrower terms in records for broader terms.

### D.6. Citation of sources

Use the 670 and 675 fields to cite sources that were consulted in preparing the proposal. See H 202 for instructions on the authority research required for subject heading proposals. See H 203 Citation of Sources for instructions on how to format the information.

#### D.6.a. Work cataloged

Cite the work for which the heading is being proposed as the first 670 field. When establishing both a new heading and a new subdivision for the same work, cite the work in both authority records. Include in a $b subfield information from the work that will be useful in evaluating the proposal.

#### D.6.b. Other sources in which the heading was found

Use additional 670 fields to cite sources that support the form of the proposal or references.

Example:

```
670 ## $a Rieger, R. Glossary of genetics, 1990 $b (genotype-environment interaction)
670 ## $a MEDLINE on 1stsearch, Feb. 15, 1996 $b (genotype-environment interaction; genotype by environment interaction; gene-environment interaction; genotype x environment interaction)
```

Do not cite LC patterns or the *Subject Headings Manual* in 670 fields. Instead, use the 952 (LC pattern) field, as described in sec. D.12 on LC patterns, below.

#### D.6.c. Sources in which the heading was not found

Use a single 675 field to cite sources that were consulted but do not include the term or any variation of it.

Example:

```
675 ## $a Lippincott; $a Columbia Gaz.; $a Times atlas; $a Britannica online, June 28, 2013
```

### D.7. Scope note

Follow the guidelines in H 400 for determining whether a scope note is appropriate. If a scope note is being provided for the heading being established, enter it in a 680 field. Use the technique described in sec. C.3.c to add a blank 680 field to the template. Use $i subfields for explanatory text and $a subfields for headings or subdivision terms that are used to amplify or illustrate the text contained in the $i subfields.

Example:

```
150 ## $a Developmental neurobiology
680 ## $i Here are entered works on the growth and differentiation of the nervous system. Works limited to the growth of the nervous system are entered under $a Nervous system--Growth.
```

Note: The introductory phrase, "Here are entered works on," is system-supplied.

### D.8. Geographic subdivision information

For geographic subject headings, enter data in the 781 field showing the form of the heading when it is used as a geographic subdivision, following the guidelines in H 830.

Note: If the heading is not valid for use as a geographic subdivision, leave the 781 field blank. When the record is saved, the system will automatically add a 667 field stating that the heading is not valid for use as a geographic subdivision. See the detailed guidelines in H 836.

### D.9. General see also references

None of the basic templates include a blank 360 field. If one is required, add it to the template using the technique described in sec. C.3.c, above. Enter the text of the reference in the blank 360 field, creating $a and $i subfields as needed, using the technique described in sec. C.3.b, above. Use $i subfields for explanatory text and $a subfields for the heading(s) or subdivision(s) referred to.

Example:

```
150 ## $a Apologetics
360 ## $i subdivision $a Apologetic works $i under individual denominations, e.g., $a Catholic Church--Apologetic works
```

Rules and guidelines for making general see also references are provided in H 371.

### D.10. General see references

To create a general see reference, use the General See Reference template mentioned in C.2.i, above. Enter the term from which the reference is being made in the 150 field. Enter the text of the reference in the blank 260 field, creating $a and $i subfields as needed, using the technique described in sec. C.3.b, above. Use $i subfields for explanatory text and $a subfields for the heading(s) or subdivision(s) referred to.

Example:

```
150 ## $a Controversial literature
260 ## $i subdivision $a Controversial literature $i under names of individual religious and monastic orders, individual religions, Christian denominations, and uniform titles of sacred works for works that argue against or express opposition to those groups or works
```

Rules and guidelines for making general see references are provided in H 374.

### D.11. Bibliographic file maintenance

Before submitting a completed proposal to PTCP, search the LC Database to locate existing bibliographic records that should be updated as a result of the new proposal. Enter the total number of records to be changed in the 952 (Bib record changes) field. If there are none, enter 0 after the standard text, "Bib. Records to be changed." If the number of records to be updated is less than fifteen, also record the LCCNs in that 952 field. If the number is greater than fifteen, add helpful information to the 952 field about how to identify the records to be updated, if known.

Note: SACO participants are encouraged, but not required, to submit information about bibliographic records to be updated in the LC Database. If doing so, provide the LCCNs of the pertinent records in the 952 (Bib record changes) field.

For detailed information about bibliographic file maintenance, see H 165.

### D.12. LC patterns

When it is appropriate to cite an LC pattern (see H 202), enter it into the 952 (LC pattern) field. Since the field already contains the words "LC pattern:" it is not necessary for the user to key in that text.

Example:

```
150 ## $a Poets, Zimbabwean
952 ## $a LC pattern: Authors, Zimbabwean
```

This information is permanently retained in the authority record for the new heading but is not distributed outside the Library of Congress.

Note: If no pattern is being cited, leave the remainder of the field blank and it will be automatically deleted by the system when the record is saved.

If the heading and/or its reference structure is being established according to a pattern prescribed in a specific instruction sheet in the *Subject Headings Manual*, add a 952 (cataloger's comments) field containing the number of the instruction sheet. Use the abbreviation SHM.

Example:

```
952 ## $a SHM H 1334
```

### D.13. Comments accompanying proposal

Enter any comments that are pertinent to the new heading in the 952 (Cataloger's comments) field. These include a description of special problems or considerations that were factors in selecting the form of the heading or references, the impact that the new proposal might have on the assignment of other headings, or other relevant facts accumulated in doing authority research for the proposal. These may be considered for permanent inclusion in the authority record.

Include in the proposal itself any information about related subject and/or class proposals, so that they may be properly grouped together on a subject list, or on the related classification list. Record this information in the 952 field.

Examples:

```
On proposal for a broader term *Boidae, Fossil* for the heading Titanoboa, add:
952 ## $a Group with related subject proposal: Titanoboa

On proposal for the heading Titanoboa that has a related classification number proposal, add:
952 ## $a Group with related class proposal: QE862.O6

On five proposals for broader terms, related terms, or impacted terms for the heading Kirāta Sirijaṅgā alphabet, add:
952 ## $a Group with related subject proposal: Kirāta Sirijaṅgā alphabet
```

### D.14. Providing an email address

Enter an email address to cause a system-generated email message to be sent when the proposal is scheduled for a tentative list and when it has been approved, rejected, or approved with modifications by the editorial meeting. A full email address must be provided, such as myname@loc.gov. Leave the field blank to avoid receiving these messages.

NOTE: Multiple email addresses may be included, but must be separated by a space, comma, pipe (|), semicolon, or colon, i.e. "myname@loc.gov secondname@gmail.com".

### D.15. Submitting the proposal

Submit the proposal(s) to PTCP by going to the wrench icon in the upper right hand corner to reveal the Tools menu and click the Submit for Review button. This will save a copy of the proposal as a PDF, send a copy of that proposal to the proposer, and forward the proposal to proposals@loc.gov with an attached PDF.

Note: This does not apply to CIP proposals. Continue to use PrePub Book Link (PPBL) system to submit CIP proposals.

LC catalogers should hold the book at their desk until PTCP has made a decision on the proposal(s). SACO catalogers will follow their own institutional procedures. The proposal system will send you an automatic email when the editorial process is complete if you input your email address into the proposal (see sec. D.14 on Providing an email address).

After the editorial process is complete, adjust the bibliographic record in accordance with the decision, if necessary, then finish processing the book according to the standard workflow.

### E. Checklist for New Subject Heading Proposals

Before submitting a new subject heading proposal to PTCP, check to see that the following procedures have all been properly followed:

**GENERAL**

- Proposal is necessary, i.e., does not use a free-floating subdivision or phrase (see H 362, H 1095-H 1200)
- Proposed heading does not duplicate an existing heading, or has not already been established in another form

**SUBJECT AUTHORITY PROPOSAL TEMPLATE**

- The appropriate radio button has been selected for "Generated by"
- The appropriate radio button has been selected for field 008/06 (Geographic subdivision), where applicable
- Class number(s) have been provided in 053 fields, where appropriate
- Number of records to be changed is shown in 952 field (0 if none)
- Proper source information has been provided in 670 field(s) and/or relevant LC pattern or instruction sheet number cited in 952 field (including notes on related proposals)
- Work generating the proposal, if any, has been cited in 670 field

**REFERENCES**

- Required pattern references have been made
- Proposed 4XXs do not conflict with existing headings or references, and are listed in alphabetical order
- Proposed 5XXs are currently valid headings or proposed new headings. Broader terms are in one alphabetical list followed by related terms in a separate alphabetical list
- For each 5XX that is a related term reference, there is an accompanying proposal for the existing heading revised to add a 5XX field with the new heading as related term
- Narrower term references have been made by following procedures in H 195 and submitting a printout of each authority record that has been changed to add the proposed heading as a 5XX

**RECORDS TO BE CHANGED**

- A list of bibliographic records has been included with the proposal (see H 165 for detailed information about bibliographic file maintenance)

### Appendix 2: Original values in field 008

Following are the default values for the 008 field in LC subject heading authority records. The 008 fields in some Subject Heading Proposal System templates are coded differently, due to the nature of the heading being proposed (i.e., in the Family Name Heading template, 008/06 is set to Not Subd Geog because family names may not be geographically subdivided).

| Character position in 008 field | Data element name | Default value |
|---|---|---|
| 008/06 | Direct/indirect geographic subdivision | \| : No attempt to code |
| 008/07 | Romanization scheme | \| : No attempt to code |
| 008/08 | Language of catalog | _ : No information provided |
| 008/09 | Kind of record | a : Established heading |
| 008/10 | Descriptive cataloging rules | n : Not applicable |
| 008/11 | Subject heading system/thesaurus | a : Library of Congress Subject Headings |
| 008/12 | Type of series | n : Not applicable |
| 008/13 | Numbered or unnumbered series | n : Not applicable |
| 008/14 | Heading use-main or added entry | b : Not appropriate |
| 008/15 | Heading use-subject added entry | a : Appropriate |
| 008/16 | Heading use-series added entry | b : Not appropriate |
| 008/17 | Type of subject subdivision | n : Not applicable |
| 008/28 | Type of government agency | \| : No attempt to code |
| 008/29 | Reference evaluation | a : Tracings are consistent with the heading |
| 008/31 | Record update in process | n : Proposed new heading (Subject only: record cannot be used but is not in update) |
| 008/32 | Undifferentiated personal name | n : Not applicable |
| 008/33 | Level of establishment | a : Fully established |
| 008/38 | Modified source | _ : Not modified |
| 008/39 | Cataloging source | \| : No attempt to code |

Note: The default value for 008/39 was # (blank), national bibliographic agency, until February 2021.
