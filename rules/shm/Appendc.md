# Appendix C Diacritics and Special Characters

## Validation rules

1. Name headings (personal, corporate, jurisdictional, uniform titles) used as subjects must carry exactly the diacritics and special characters of the name authority record (LC romanization). (Appendix C sec. 1)
2. Accent marks over uppercase letters in French, Portuguese, and Spanish are valid (the prohibition was rescinded in February 2006), e.g. `Basques, Île aux (Québec)`; older name headings may still lack them. (Appendix C sec. 1, 4)
3. Existing subject headings and subdivisions must match the subject authority record exactly, including diacritics and special characters. (Appendix C sec. 2)
4. When establishing a heading, prefer the form without diacritics if it is clearly the conventional English form (e.g. `Kshatriyas`, `Nirvana`, `Antiparos Island (Greece)`); if no conventional English form exists, use the Britannica / discipline-reference form with diacritics per LC romanization. (Appendix C sec. 3)
5. Diacritics in headings and references follow LC transcription/romanization conventions even where BGN or other sources show different diacritics (e.g. BGN left hook under S becomes dot under Ṣ). (Appendix C sec. 4)
6. Do not make 4XX references that differ from the heading only by diacritics (e.g. no `Dráva River` under `Drava River`, no `Nirvāṇa` under `Nirvana`, no `Chʻeng family` under `Cheng family`). (Appendix C sec. 5)
7. Superscript and subscript characters are transcribed as ordinary on-line characters, e.g. `C*-algebras`, `L1 algebras`, `Lp spaces`. (Appendix C sec. 6)
8. Greek and Hebrew letters must not appear in headings or references; romanize them (e.g. `Chi Rho symbol` not `ΧΡ symbol`, `Chi-square test` not `χ-square test`, `Lambda calculus` not `λ calculus`, `Pi` not `π`). A heading string containing Greek or Hebrew script letters is invalid. (Appendix C sec. 7)
9. Do not use `&` in form or topical subdivisions or to connect two words in a geographic qualifier; spell out `and` in subject headings. (Appendix C sec. 8)
10. Exception: name headings established with `&` keep it when used as subjects (e.g. `C.S. Wertsner & Son.`, `Dow Jones & Co.`). (Appendix C sec. 8)
11. Distinguish lookalike marks: the acute (´) is not the soft sign (ʹ) or apostrophe ('); the alif (ʼ) is not the ayn (ʻ), acute, soft sign, or apostrophe; the circle above (å) is not the dot above; the cedilla (ç) is not the left hook (ą, ș); the circle below is not the dot below (ṣ); the breve (ŏ) is not the hacek (č); the Hungarian double acute (ő, ű) is not the umlaut (ö, ü), the tverdyi znak (ʺ), or the quotation mark ("). (Appendix C sec. 9)
12. The Turkish dotless i (ı) is distinct from regular i; uppercase dotless ı is rendered `I`. Polish ł is distinct from regular l. (Appendix C sec. 9.s, 9.v)
13. The double acute appears only in Hungarian. (Appendix C sec. 9.l)

## Full text

**BACKGROUND:** Diacritics are marks placed over, under, or through letters or combinations of letters that indicate differences in pronunciation and meaning between the marked letter and its unmarked counterpart. Common diacritics are the umlaut (for example, ü), the acute (for example, ó), the grave (for example, à), and the macron (for example, ō). Double diacritics are two diacritics modifying a single letter, for example, Nguyễn. Special characters occupy a place of their own rather than modifying a letter. Common special characters include the Polish l (ł), miagkiĭ znak (ʹ), the ayn (ʻ), and the alif (ʼ). Superscript characters are letters, numbers, or symbols written or printed higher on a line of text; subscript characters are letters, numbers, or symbols written or printed lower on a line of text.

**PLACEMENT OF DIACRITICS IN LCSH:** In LCSH diacritics and special characters are generally printed in accordance with either the LC romanization conventions for a particular language or with a conventional form found in reference sources.

### 1. Policy for headings established in the name authority file and used as subject headings

Transcribe from name authority records valid personal, corporate, and jurisdictional names and uniform titles, with all indicated diacritics and special characters placed in accordance with LC's transcription or romanization conventions for a particular language.

**Accent marks over uppercased letters in French, Portuguese, and Spanish.** In February 2006 the previous prohibition on use of accent marks over uppercased letters in French, Portuguese, and Spanish was rescinded. Name headings established or revised after that date reflect the changed policy.

### 2. Policy for headings established in the subject authority file

Transcribe existing headings and subdivisions exactly as they have been established in the subject authority file, using diacritics and special characters as indicated.

### 3. Establishing subject headings with or without diacritics

When, as a result of doing authority research, a choice must be made between a term without diacritics and the otherwise identical term with diacritics, generally prefer the term without diacritics if it is clearly the conventional English form. If there is no conventional English form, prefer the form of the term as found in the *Encyclopaedia Britannica* or in reference sources of the particular discipline or language, using diacritics to conform to LC's transcription or romanization conventions.

### 4. Diacritic use and LC practice

If it is determined that a heading or reference is to have diacritics, use diacritics that conform to LC transcription or romanization conventions, even if reference sources, including BGN, indicate different diacritics. Use judgment in determining whether to make UF references from forms with variant diacritics that are spelled differently from the proposed heading. (For forms that have variant diacritics but are spelled the same as the proposed heading, see sec. 5, below.) Examples:

```
BGN approved form:
Jabal Ș̄āʼid, mountain   [garbled in source: extracted as "S_~'id"; S with left hook below]

Heading as established:
151 ## $a Ṣāʼid Mountain (Saudi Arabia)
[BGN left hook under S changed to dot under Ṣ to conform to LC romanization practice; reference not made from Sa'id since spelling is identical.]

BGN approved form:
Nísos Andíparos

Heading as established:
151 ## $a Antiparos Island (Greece)
451 ## $a Andiparos Island (Greece)
451 ## $a Nísos Andíparos (Greece)
[Accent marks supplied by BGN in second 451 field]

Encyclopaedia Britannica:
Kṣatriya

Heading as established:
150 ## $a Kshatriyas
450 ## $a Kṣatriyas
[Since spelling is not identical, UF reference made from the form based on Sanskrit with dot under ṣ to conventional English plural form.]
```

**Accent marks over uppercased letters in French, Portuguese, and Spanish.** Add diacritics according to the usage of the language. Example:

```
151 ## $a Basques, Île aux (Québec)
```

### 5. Diacritics in subject headings and references

Because some online systems cannot distinguish between a term without diacritics and the otherwise identically spelled term with diacritics, do not add 4XX fields for variants of this type, even if the terms do not represent the same word in a particular language. The following are examples of 4XX fields that should not be made:

```
100 3# $a Cheng family
400 3# $a Chʻeng family

100 3# $a Ota family
400 3# $a Ōta family   [extracted as "Æta"; macron O intended]
```

Note: For instructions on headings for family names of different meanings or different ethnic backgrounds that are distinguished only by the use of diacritical marks, see H 1631, sec. 3.c.

```
150 ## $a Nirvana
450 ## $a Nirvāṇa

151 ## $a Drava River
451 ## $a Dráva River
```

### 6. Superscript/Subscript characters

Since superscript or subscript characters are positioned on the same line as the rest of the heading both in the online authority and bibliographic records, as well as in the printed edition of LCSH, treat them as normal characters rather than as superscript or subscript characters. Examples:

```
Term: C*-algebras
Transcribe as:
150 ## $a C*-algebras

Term: L1 algebras   [1 printed as subscript/superscript]
Transcribe as:
150 ## $a L1 algebras

Term: Lp spaces   [p printed as superscript]
Transcribe as:
150 ## $a Lp spaces
```

### 7. Greek or Hebrew letters

Romanize Greek or Hebrew letters when establishing subject headings. Do not use Greek or Hebrew letters in headings or references, even though they appear as such in reference sources. Examples:

```
150 ## $a Chi Rho symbol
  [not 150 ## $a ΧΡ symbol]

150 ## $a Chi-square test
  [not 150 ## $a χ-square test]

150 ## $a Lambda calculus
  [not 150 ## $a λ calculus]

150 ## $a Pi
  [not 150 ## $a π ]
```

### 8. Ampersands

Do not use ampersands in form or topical subdivisions, or to connect two words in the qualifier of a geographic heading. In subject headings, spell out ampersands using the word *and*.

Exception: When assigning as a subject heading a name heading established with an ampersand, use the ampersand. Examples:

```
610 20 $a C.S. Wertsner & Son.
610 20 $a Dow Jones & Co.
```

### 9. Common diacritics and special characters

#### a. Acute ( ´ )

```
Avalokiteśvara (Buddhist deity)
Cévennes Mountains (France)
Daśnāmīs
Mossoró (Race horse)
```

Do not confuse this diacritic with the miagkiĭ znak ( ʹ ) and the apostrophe ( ' ), which are special characters.

#### b. Alif ( ʼ )

```
Ṣāʼid Mountain (Saudi Arabia)   [extracted as "S_~'id"]
```

Do not confuse with the acute ( ´ ), the miagkiĭ znak ( ʹ ), the apostrophe ( ' ), or the ayn ( ʻ ).

#### c. Angstrom or Circle above letter ( ˚ )

```
Skovsgåard (Denmark)   [as extracted]
Småland (Sweden)
Lundsgård (Denmark)
```

Do not confuse with the dot above letter ( ˙ ).

#### d. Apostrophe ( ' )

```
Coups d'état
Martin's Hundred Site (Va.)
```

Do not confuse with the acute ( ´ ), the miagkiĭ znak ( ʹ ), the alif ( ʼ ), the ayn ( ʻ ), or the grave ( ` ).

#### e. Ayn ( ʻ )

```
ʻĪd al-Ghadīr
Shīʻah
```

Do not confuse with the acute ( ´ ), the miagkiĭ znak ( ʹ ), the alif ( ʼ ), or the apostrophe ( ' ).

#### f. Breve ( ˘ )

```
Bolʹshoĭ prospekt (Saint Petersburg, Russia)
Hanmun sosŏl (Korean fiction)
Umilenīi͡e T͡Sarit͡sy Nebesnoĭ (Icon)   [garbled in source: extracted as "Umilen§iMe TMSaritMsy Nebeso0 (Icon)"; decoding uncertain]

Do not confuse with the hacek ( ˇ ).

#### g. Cedilla ( ¸ )

```

Do not confuse with the left hook ( ˛ ).

#### h. Circle below letter ( ̥ )

```

#### i. Circumflex ( ^ )

#### k. Dot below letter ( . )

```

Kuṇḍalinī

#### l. Double acute ( ˝ )

```
Hungary. Földművelésügyi Minisztérium   [extracted as "Földmávelésügyi"; ű intended]
```

This diacritic appears only in Hungarian. Do not confuse with the tverdyi znak ( ʺ ), a special character that follows the letter it modifies, the Umlaut ( ¨ ), or the standard quote mark ( " ).

#### m. Grave ( ` )

#### s. Polish l ( ł )

#### v. Turkish i ( ı )

Note that ı is not dotted. If uppercased, render as I. Turkish also has a regular i.

#### w. Tverdyi znak ( ʺ )

```

```

Do not confuse this special character with the double acute ( ˝ ) of Hungarian, the umlaut ( ¨ ), or the standard quote mark ( " ).

Do not confuse this diacritic with the double acute ( ˝ ) of Hungarian, the tverdyi znak ( ʺ ), or the standard quote mark ( " ).
