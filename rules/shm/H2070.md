# H 2070 Software and Works about Software

## Validation rules

1. Headings for individual computer programs (and, since 2017, software frameworks and packages) are name authority headings, usually uniform titles (130/630) or occasionally author-title (100/110/111); they are not 150/650 topical headings (pre-1987 practice). (H 2070 background)
2. `--Software` is a free-floating form subdivision used under every heading assigned to software, e.g. `Engineering--Software`, `Electronic spreadsheets--Software`, `Computer adventure games--Software`. (H 2070 sec. 1.a)
3. Use `--Juvenile software` instead of `--Software` when the title is coded for intellectual level a, b, or c (juvenile audience). (H 2070 sec. 1.a)
4. Do not use `--Computer programs` when cataloging software; `--Computer programs` is only for works about computer programs, e.g. `Business--Computer programs`. (H 2070 sec. 1.a, 2.b)
5. Do not assign subject headings for program language, computer make/model, or operating system of software being cataloged. (H 2070 sec. 1.b)
6. Do not assign the heading for a named program (e.g. `Lotus 1-2-3 (Computer file)`) to the program itself; assign it only to works about the program. (H 2070 sec. 1.c)
7. A named program heading is usually `[name of program]` without qualifier, a qualifier added only for conflict; current examples use the qualifier `(Computer file)`, e.g. `Lotus 1-2-3 (Computer file)`, `WordPerfect (Computer file)`. Do not treat the GMD `[computer file]` as part of a heading taken from a 245 field. (H 2070 sec. 2.a)
8. [LC practice] With a named program heading, assign at least one topical heading for the topic or application. (H 2070 sec. 2.b)
9. `--Bibliography` under `Computer software` or `[topic]--Software` is only for lists of books about software; `--Catalogs` is for lists of the software itself. (H 2070 sec. 3)

## Full text

BACKGROUND: Before 1987, headings for individual computer programs had been established as subject headings and were tagged 150 in authority records and 650 in bibliographic records. Since 1987, headings for individual computer programs are established, when needed, in the name authority file rather than the subject authority file. Since 2017, headings for software frameworks and software packages have also been established in the name authority file.

The headings are usually uniform titles tagged 130, but occasionally they are in author-title form tagged 100, 110, or 111. This instruction sheet describes the principles to be followed in assigning subject headings to computer software and to works about individual computer programs. For general procedures on classifying software, see F 710. For guidelines on assigning subject headings to databases, see H 1520.

### 1. Software

Note: These provisions apply specifically to works cataloged as software, not to works cataloged as books with accompanying software. For principles to be followed in cataloging works of the latter type, see H 180, sec. 1.

#### a. Assigning subject headings

Assign at least one subject heading to every software title to bring out the topic(s) or genre of the software. Follow the same principles as to number and specificity of headings as are followed for books.

Use the free-floating form subdivision --Software under each heading assigned, for example, Engineering--Software, Electronic spreadsheets--Software, Computer adventure games--Software. If the title has been coded for intellectual level a, b, or c in field 008/22 (the box labeled Audience on the 008 input screen in the LC ILS), use the free-floating subdivision --Juvenile software under the headings assigned. Do not use the subdivision --Computer programs when cataloging software. Use --Computer programs only for works about computer programs.

#### b. Elements that are not brought out in subject headings

Do not assign subject headings to bring out the program language, the make or model of the computer, or the operating system, since access to these elements is provided in the descriptive cataloging data.

#### c. When to assign the heading for a named computer program

Do not assign the heading for a named computer program to the program itself. Do not, for example, assign Lotus 1-2-3 (Computer file) when cataloging the Lotus 1-2-3 software. Instead, assign the appropriate topical headings, for example, Electronic spreadsheets--Software and Business--Software. Assign Lotus 1-2-3 (Computer file) only to works about the program, for example, a book, a film, a periodical, or a package of software about Lotus 1-2-3 (see sec. 2, below).

#### d. Establishing topical or genre headings

Establish new topical or genre headings as required, according to the same criteria followed in cataloging books and other media.

### 2. Works about individual computer programs

LC practice:

#### a. Assigning the name heading

When assigning the heading for a named computer program to a work about the program, first search the LC Database to determine whether a name authority record has been created for the program. The name heading is usually in the form [name of program] with no qualifier although occasionally a program may be established as an author-title combination. In the event of conflict, a qualifier may be added.

- If an authority record is found, assign the heading in the form provided in the record.
- If an authority record is not found, search the file of bibliographic records to determine whether the program itself has been cataloged by the Library of Congress.
  - If a bibliographic record is found and the main entry is under title, assign the title as a subject heading in the form found in the 245 field. Do not treat the general material designation [computer file] as part of the heading. If main entry is under a personal or corporate name, assign a name-title combination as the subject heading, in the same manner as for commentaries (cf. H 1435). If in doubt as to the form to use as subject heading, consult a descriptive cataloger.
  - If a bibliographic record is not found, establish a heading for the program in the name authority file.

#### b. Assigning topical headings

In addition to the heading for the name of the program, assign at least one heading to bring out the topic or application of the program. Examples:

```
Title: The best book of Lotus 1-2-3.
630 00 $a Lotus 1-2-3 (Computer file)
650 #0 $a Business $x Computer programs.

Title: The WordPerfect book.
630 00 $a WordPerfect (Computer file)
650 #0 $a Word processing.
```

### 3. Bibliography and catalogs of software

Use the form subdivision --Bibliography under the heading Computer software or under headings of the type [topic]--Software only for lists of books about software. Use --Catalogs only for lists of the software itself.
